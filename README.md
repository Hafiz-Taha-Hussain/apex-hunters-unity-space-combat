# Apex Hunters

A 3D space combat game built in Unity, featuring dogfighting, AI-controlled enemies, and a lock-on weapon system across two levels of progression.

## Overview

Apex Hunters was built as a Game Development course project, combining flight controls, enemy AI, and combat systems into a full playable space combat experience. Developed over one semester with a focus on core gameplay feel — responsive flight, readable combat feedback, and a working progression loop.

## Tech Stack

- **Engine:** Unity 6 (URP — Universal Render Pipeline)
- **Language:** C#

## Features

- **Flight Controller** — Full 3D flight movement and controls for the player ship
- **UFO AI State Machine** — Enemy AI with distinct behavioral states for patrol, engagement, and combat
- **Lock-On Weapon System** — Target acquisition and lock-on based combat mechanics
- **Game Manager** — Core game state handling (win/loss conditions, level flow, game state transitions)
- **HUD** — In-game heads-up display for combat and flight feedback
- **Sound Design** — Custom sound effects and audio implementation
- **Two-Level Progression** — Structured level progression from start to finish

## Getting Started

1. Clone the repository
   ```
   git clone <repo-url>
   ```
2. Open the project folder in **Unity Hub** (requires Unity 6)
3. Let Unity import assets and resolve packages
4. Open the main scene and press Play
